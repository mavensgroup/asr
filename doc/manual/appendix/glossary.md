# Glossary

| Term | Meaning |
|---|---|
| **ASA** | Atomic-sphere approximation: space-filling spheres, spherical potentials |
| **ASR** | Augmented-space recursion |
| **Augmented space** | Enlarged Hilbert space in which configuration averages become expectation values of a Hermitian operator |
| **Node** | A basis state \(|R,\{\text{flipped sites}\}\rangle\) of the augmented space |
| **Rank** | Maximum number of flipped sites in a node (`[asr] rank`) |
| **Levels / depth** | Number of Lanczos levels (`[asr] levels`) |
| **Haydock recursion** | Lanczos tridiagonalisation of \(H\) from a local start state |
| **Terminator** | Approximation of the continued-fraction tail beyond the computed levels |
| **CPA** | Coherent-potential approximation, the single-site mean-field theory ASR goes beyond |
| **TB-LMTO** | Tight-binding (screened) linear muffin-tin orbitals |
| **\(\alpha\) / \(\gamma\) representation** | Screened and \(\gamma\)-based parameter representations of the LMTO Hamiltonian |
| **\(E_\nu, C, \Delta, p, \gamma\)** | Linearisation energy; band centre; band-width parameter; overlap parameter \(\langle\dot\phi|\dot\phi\rangle\); \(\gamma\) of the \(\gamma\) representation |
| **\(H^{(2)}, H^{(3)}\)** | Orthonormal ASA Hamiltonian to second / third order in \(h\) |
| **Potential function \(P(z)\)** | \(P^\alpha=(z-C)/(\Delta+(\gamma-\alpha)(z-C))\) |
| **KKR-ASA** | Green-function ASA with the exact (non-linearised) potential function |
| **SIM** | Screened Impurity Model for the electrostatics of random alloys |
| **SQS** | Special quasirandom structure |
| **HEA** | High-entropy alloy |
| **SRO** | Short-range order |
| **Contour** | Complex-energy path for integrating Green functions |
| **FORD** | FORtran Documentation generator used for this site |
| **Decoration cell** | Cell whose positions assign graph sites to sublattices (`kind = "sublattice"`) |
| **Graph lattice** | The sc/bcc/fcc lattice on which hopping is defined |
| **Class** | Inequivalent ASA sphere |
