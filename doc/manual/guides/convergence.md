# Convergence guide

A disordered calculation has more convergence parameters than an ordered one
and they are *not* equally forgiving. This page ranks them and gives a
protocol. The key fact: **depth is the lever** — no terminator rescues a
shallow recursion on a real d band (see [Recursion and
terminators](../theory/recursion.html)).

## Parameters ranked by importance

| Parameter | Controls | Typical cost | How to test |
|---|---|---|---|
| `levels` | Resolution of the LDOS; moments of magnetic d bands | **Exponential** in node count | Increase until DOS (and moments, \(E_F\)) stop changing |
| `rank` | Environment fluctuations kept | Large | 1 → 2; the effect is usually smaller than depth |
| `supercell` | Periodic graph size | Mild | Must exceed what `levels` can reach; enlarge until nothing changes |
| `flip_radius` | Locality of flips | Mild | Default 99 (unlimited); reduce only to save time after testing |
| `contour_points` | Accuracy of moments and \(E_F\) | Linear | 32 → 60 → 80 |
| `fermi_kt`, `fermi_poles` | Smoothness of \(N(E_F)\) | small | Small `fermi_kt` (1 mRy) stabilises the SCF |
| `nk` (`lmto`) | k-mesh | cubic | 12 → 16 → 24; compare moments and \(N(E_F)\) |
| `tolerance`, `mixing` | SCF | — | Tighten after the parameters above |

## Protocol

1. **Cheap pass.** `levels = 3–4`, `rank = 1`, small `supercell`. Confirms input,
   chemistry and that the SCF converges (a few minutes).
2. **Depth scan.** Run `levels = 4, 6, 8, …` as far as memory allows. Plot the
   species DOS and tabulate \(E_F\), moments, net charges. Stop when changes fall
   below the physical question you ask.
3. **Rank.** Repeat the best depth with `rank + 1`.
4. **Supercell.** Double `supercell` once at the best depth.
5. **Cross-check the route.** `route = "edc"` and `route = "ed3"` differ by the
   \(hph\) term of the Hamiltonian, not by truncation, so their difference is a
   Hamiltonian effect. To judge truncation compare two depths of the same route.
6. **Final.** Tighten `tolerance` and `contour_points`.

!!! warning "Warning signs"
    * Negative l-resolved DOS at some energies (seen in the shipped
      `levels = 3` CuZn example for Zn d at \(E_F\)).
    * Moments or \(E_F\) that keep drifting with `levels`.
    * A magnetic moment that *disappears* as `levels` is reduced: the pure-Ni
      limit through the alloy route at depth 3 loses its moment (0.5 μ<sub>B</sub> →
      10⁻⁴) while the ordered route gives 0.64, so the zero moment is a
      resolution limitation, not a disorder effect. Fe (also with \(E_F\)
      in the d band) was fine at 8–16 levels.

## Memory and node counts

The augmented-space node count grows steeply. Rough numbers measured for
Cu-Ni without symmetry: ≈ 2·10⁶ nodes at depth 3 and ≈ 4·10⁷ at depth 4
(rank ≤ 2). The D\(_{4h}\) symmetry reduction (always on in the recursion) cuts it by
≈ 40×. For an energy-independent CuZn test (`levels = 3`, `rank = 2`,
`supercell = 8`) the report showed

```text
augmented-space nodes 63175   D4h symmetry=T
```

The reduction is exact.

!!! tip "Hard walls"
    `recursion_steps` larger than `levels` runs more Lanczos steps on the node
    set generated by `levels` hops, as a hard wall. It gives extra resolution at
    nearly constant memory (as in AMscf: map exact to 6 hops, 12 steps). The
    shipped Heusler example uses `levels = 4`, `recursion_steps = 24`.

## Energy-dependent route

* `depth_tol` makes each chain stop once \(G\) is stable, so `levels` acts only as an
  upper bound; the statistics (`ed_nchain`, `ed_nlev`) show how deep chains
  really went.
* `ed_terminator`: keep the default `hull`. At 24 or 36 steps all three tails
  agree within 0.005 muB. The `tail_scan` diagnostic prints the moments against
  termination depth for each tail, each at its own \(E_F\). Do not use `bp` for
  SCF runs (see [Recursion and terminators](../theory/recursion.html)).
* `fermi_kt` > 0 helps the SCF because \(N(E_F)\) becomes smooth.
* Long chains on ordered cells carry a length error near \(10^{-3}\) e. On B2
  CuZn (route `ed3`, supercell 16) the Cu charge transfer is 0.13 e. It moves
  by \(7.8\times10^{-4}\) e from 96 to 256 steps, and \(E_F\) by 1.1 mRy. Between 64 and 192
  steps the result also depends on rounding by a few \(10^{-4}\) e. So
  `energy_block` 0 and 8, or a run with a different rounding, can differ by
  that much. At 48 and at 256 steps all versions agree. This is far below the
  accuracy of the method. Do not read differences below \(10^{-3}\) e between
  such runs as physics.

## Ordered limits as tests

Setting both species equal (A = B, a "trivial alloy") must reproduce the ordered
SCF. `test_alloy_scf` verifies this, so it is a good sanity check of any new
settings: run the A = B alloy by `method = "asr"` and compare with `method = "kspace"` on the same structure.
