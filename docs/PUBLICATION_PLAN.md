# Publication plan: CPC code paper, first PRB (bcc Fe-Cr)  (2026-10-21)

Status: plan only.  Nothing here is implemented beyond what `docs/STATUS.md` lists.  Literature claims marked *(unverified)* are from
memory and must be checked against the primary source before they go into a manuscript or a gate.

## Order
1. SRO (`docs/ROADMAP.md` phase 6; gates from `docs/archive/HANDOFF_hea_sro.md` Part B) stabilises: gates B4.1-B4.5 pass.
2. Freeze v1.0 (scope below); the CPC preprint goes on arXiv first.
3. PRB bcc Fe-Cr, written from the same binary and runs as the CPC validation; submitted without waiting for the CPC review.
4. Wannier front end (section 4), after v1.0 and Fe-Cr.  Not part of v1.0: it would delay CPC and adds nothing to it.  It serves a
   possible high-profile paper (Nature Computational Science) only together with a science result the LMTO-ASA path cannot reach.

## 1. CPC (Computer Physics Communications, Computer Programs in Physics)
Venue: CPC (Questaal and several KKR codes were published there; CPC Program Library archive).  Fallbacks: Electronic Structure (IOP)
code paper; a combined method + application PRB.  JOSS alone gives too little credit for the physics validation.

Pitch: open-source, self-consistent, energy-dependent TB-LMTO-ASR (`asr_ed`) for multicomponent, partially ordered alloys with SRO, all
LMTO parameters generated by the code itself, every stage gated against an independent reference.  Without one capability beyond CPA it
reads as "a slower CPA", so SRO is a must-have.

### Already in hand (see STATUS.md)
- Own LMTO-ASA: radial solver, libxc, atom SCF, potential parameters, Madelung, spin; == Questaal `lm` (non-magnetic MnCr/Cr <1-2 mRy).
- Augmented space exact vs brute force (binary, N-species, multi-orbital); D4h reduction.
- Disordered binaries vs one-potential-per-species SQS within 3-4%; Heusler L2_1 partial disorder within ~4% (Co 5-8%).
- General site-class operator, one TOML input, FORD manual, MIT licence, public repository, unit tests.

### Must-have before submission
- [ ] **SRO** (Part B) with gates B4.1-B4.5; the demonstration is CuZn (Tarafder) and/or Fe66Ni14Cr20 (Alam 2009).
- [ ] **HEA SCF robust**: Fe66Ni14Cr20 levels 4 converges (trial/a1/l4; Anderson restart fixes b727ff4, 5c8075e).
- [ ] **Cost table**: wall time / memory vs levels, steps, components, threads; OpenMP scaling over chains.  Cheap wins first: O_h instead
      of the D4h subgroup for cubic sublattices (up to ~3x fewer nodes), fewer full contour redos in the E_F search.
- [ ] **Portability**: gfortran + OpenBLAS build (currently ifx + MKL only, `env.sh`; never tried with gfortran).
- [ ] **One documented route**: `asr_ed` is production; EI H^(2)/H^(3), P(z)-S and KKR-ASA become documented cross-check options or
      are removed from the user-facing manual.
- [ ] **Validation rerun with the tagged binary**: many STATUS numbers predate the SIM fix (326759b), the mixing fixes and smearing.
      Figures: convergence in levels / steps / contour; ASR vs SQS (binaries, Heusler, ternary); ASR vs CPA where available (FeRh vs
      SPR-KKR-CPA, STATUS q11); ordered vs Questaal / Elk.
- [ ] **Short test runs with reference outputs** (CPC requirement); the full `fpm test` takes >20 min.
- [ ] **Known discrepancies explained or documented**: Ag 10-30 mRy offsets; Heusler Co 5-8% low; FeRh Fe -4.8% vs SQS;
      bcc Fe moment 1% below Questaal.

### Strongly recommended
- [ ] Alloy mixing energies vs SQS (total energy exists since b727ff4, checked only on fcc Cu: a0 3.546 A, B 199 GPa).

## 2. First PRB: bcc Fe-Cr, Fe-rich side
Why: a binary, so effects are attributable to SRO or magnetism alone; Cr moments antiparallel to and frustrated by the Fe host; SRO known
to change sign with concentration *(unverified: neutron diffuse scattering, Mirebeau, Hennion & Parette, PRL 1984)*; experiment to compare with.

Framing: what a supercell does not give.  Configurational average with no supercell-size or sampling noise, and SRO as a continuous
parameter: **moments and DOS as smooth functions of alpha**, and **moments vs local environment** (number of Cr nearest neighbours).
Not a reproduction of known Fe-Cr results.

Scope:
- In: Fe-rich bcc, collinear, ferromagnetic host (concentration range to be fixed after a literature check of the magnetic phase diagram).
- Out: Cr-rich side (spin-density wave), dilute / spin-glass region (needs noncollinear), J_ij.
- Stretch: E(alpha) at fixed x (ordering tendency).  Fe-Cr energy scales are of order meV/atom *(unverified, e.g. Olsson et al.
  2003 EMTO-CPA mixing enthalpy)*, below what we can trust from total-energy differences today.  If needed, use orbital-peeling pair
  energies (docs/JIJ_PLAN.md section 4), not total-energy subtraction.
- Follow-ups: CrFeCoNi (needs 4-component SRO and the Fe-Ni-Cr gate), FeCrMn / FeCrAl as a transferability paragraph at most;
  FeCuCrMnMo out.

### Prerequisites and gates (in order)
1. SRO gates B4.1-B4.4 (alpha = 0 identity, brute force, CuZn Tarafder, Alam Fe-Ni-Cr).
2. **Environment-frozen embedding**: Part B gives per-species moments vs alpha (centre frozen, shell with conditional concentrations).
   Moments vs number of Cr neighbours need the centre AND its first-shell configuration frozen inside the averaged medium (extend
   `augn_freeze_site` / `augorb_freeze_site` to a set of sites; symmetry drops to the subgroup preserving that configuration).
   Decide: environment potentials frozen at the averaged SCF (post-processing) or a local SCF of the centre.  Gate: with all shell
   sites frozen to the averaged concentrations' expectation, the weighted sum over configurations reproduces the per-species result.
3. **Same-model reference** (B4.5): reverse-Monte-Carlo supercells at target alpha (tool next to `tools/sqs.py`), k-space ASA with one
   potential per species; plus supercell results that resolve moments by environment from the literature *(to collect)*.
4. bcc Fe-Cr runs: concentration series, alpha series, magnetic start with Cr `spin_sign = -1` (exists), depth as in STATUS "Tail scan at fixed potential"
   (Cr moments are not weak-edge moments in Fe, but check 24 vs 36 steps).
5. Optional: E(alpha) at fixed x (stretch).

### Before committing: novelty check
Collect and read: earlier augmented-space / ASR Fe-Cr work; KKR-CPA and KKR-NLCPA Fe-Cr (SRO, moments); supercell DFT + Monte Carlo /
magnetic cluster expansion Fe-Cr studies; the experimental SRO and moment data.  None of these has been checked yet.

## 3. Other PRB candidates (after Fe-Cr)
- Heusler antisite / partial disorder + SRO (half-metallicity vs disorder): machinery mostly exists.
- Magnetic HEA (Fe-Ni-Cr, Cantor family) moments and charge transfer vs SRO; may need DLM for frustrated Cr.
- Disordered altermagnets: needs the configuration-averaged Bloch spectral function A(k,E) (not implemented; M8/M9).

## 4. Wannier front end and a high-profile paper (after Fe-Cr)  (added 2026-10-30)
A `_hr.dat` reader alone is an interface, not a result: it suits a CPC / JOSS update, not Nature Computational Science.  Wannier-based
disorder is not new *(unverified: Berlijn, Volja & Ku, PRL 2011; Wannier tight-binding CPA; large-supercell KPM)*.  Wannier helps only
by lifting the ASA restriction to open / layered structures, oxides and 2D alloys, and only after the operator work below.
OpenMX goes through the same front end (its built-in MLWF `.HWR` output, or a Wannier90 export if the version has one *(to check)*); its
non-orthogonal NAO basis is not read directly.

### Steps (in order)
1. **Ordered, k-space** (days): generalise `kgrid_op` (`src/asr_lmto_ham.f90`) from one 9x9 block to N_wan orbitals and several sites
   per cell; `_hr.dat` reader (degeneracies, complex H(R)); Fermi level from a fixed electron count (no SCF).  Gate: DOS and bands vs
   the source DFT / Wannier90 interpolation.
2. **Operator generalisation** (weeks): remove the spd assumptions (`orb_l`, nl = 9 literals in augsym / augcls / asr_ed, s/p/d DOS
   columns); bond blocks per (class, class', slot) instead of one block per slot; symmetry reduction for orbitals that are not real
   harmonics (representation matrices from Wannier90 site symmetry, else the unreduced operator).  Gate: an spd Wannier model built
   from our own LMTO H^(2) reproduces the existing EI results.
3. **General off-diagonal disorder** (weeks): t_ij = t^BB + (t^AB - t^BB)(n_i + n_j) + (t^AA - 2 t^AB + t^BB) n_i n_j (N-species with
   projectors), still a site-based augmented space; hops flip configurations at both bond ends.  Gate: brute-force configuration
   average on a small cluster, as for the existing operators.
4. **Hopping range**: MLWF hoppings reach further than screened S^alpha and the augmented space grows steeply with coordination.
   Truncation radius with a convergence test (DOS, moments) before any production run.
5. **Parameter extraction**: species-resolved on-site and hopping blocks with a common energy reference and the alloy charge transfer.
   Wannierise an SQS supercell or a VCA run, not separate pure-A and pure-B runs (no common zero).  Gate: Wannier-ASR vs the SQS it
   came from, within the 3-4% target.

### High-profile candidates (choose the science first)
- **CrFeCoNi, SRO-resolved magnetism, existing LMTO path** (no Wannier needed): validated vs SQS / experiment, with a clear cost
  advantage over supercells.  Follows the section 2 stretch goal.
- **Wannier-ASR on a non-close-packed disordered system with ARPES data**: needs steps 1-5 and the configuration-averaged Bloch spectral
  function A(k,E) (M8/M9).  Months of work.

### Before committing: novelty check
Collect and read: Wannier-based disorder methods (Berlijn-Ku unfolding, Wannier TB-CPA, KPM supercells), ASR with off-diagonal disorder
(Mookerjee and co-workers), and the ARPES data for the chosen system.  None of these has been checked yet.
