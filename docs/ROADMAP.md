# ASR roadmap

Updated 2026-11-08.  Status per item: 🟢 done · 🟠 in progress · 🔴 not started · ⛔ blocker (holds up later items).
Evidence for every 🟢 is in `docs/STATUS.md` and `docs/FINDINGS_LOG.md`.  Publication details: `docs/PUBLICATION_PLAN.md`.

## Goal
A self-consistent, energy-dependent TB-LMTO augmented-space recursion (ASR) code for disorder that CPA handles badly: multicomponent
and partially ordered alloys, short-range order, local environments.  First outputs: a CPC code paper (v1.0) and a PRB on bcc Fe-Cr.

## Fixed decisions
| item | decision |
|---|---|
| production method | energy-dependent ASR in the literal AMscf form (`asr_ed` / `asr_edc`): Delta_c scaling, central site frozen to one species |
| cross-checks only | energy-independent H^(2)/H^(3) route, P(z) - S route, exact KKR-ASA route, k-space LMTO-ASA, SQS supercells |
| LMTO parameters | generated by our own code; AMscf and Questaal are reference code only |
| input | one program `asr`, one TOML format; `method = "asr"` (default) or `"kspace"` (ordered cells) |
| accuracy bar | 3 to 4 % against the same-model reference (SQS with one potential per species); do not chase exact agreement |
| toolchain | fpm, Intel ifx, MKL, libxc, OpenMP over chains; MPI only after a measured need |
| compute | all calculations on the desktop; the laptop runs unit tests only |

### 6. Short-range order 🟠
Model: first-shell Warren-Cowley, centre-shell correlations only (Mookerjee and Prasad 1993; Alam and Mookerjee 2009).  The frozen
centre of `asr_ed` makes the shell of component c uncorrelated with concentrations X^(c).
| item | status |
|---|---|
| B1/B2 formalism and code (`asr_sro`, shell class in `asr_augcls`, `[[sro]]` input) | 🟢 committed `176a727` (2026-10-30) |
| B4.1 alpha = 0 gives the uncorrelated result (unit test and SCF gate G1) | 🟢 |
| B4.2 brute force: ring with frozen centre and conditional shell, and reduced vs unreduced fcc | 🟢 |
| B3 electrostatics with SRO: SIM unchanged is the default (decided 2026-10-31); option (b) `[scf] sro_shell` for the sensitivity test (`b963d0f`) | 🟢 default; 🟠 test runs queued (`trial/b45/asr`) |
| B4.3 Tarafder 2006 CuZn: SRO-induced change of the DOS | 🟢 B2 limit and main Zn peak; 🟠 Cu band at moderate alpha (FINDINGS_LOG "Gate B4.3") |
| B4.4 Alam 2009 Fig. 4 and 5: DOS shapes and the M2 ordering for the alpha triads | 🟢 done at levels 3 and 4 (`hull`); the size gap comes from the paper's random alloy (Fig. 2: about 2 e off Cr) |
| B4.5 same-model reference: reverse Monte Carlo supercells at target alpha | 🟢 DOS shape (widths, peaks); 🔴 energies and band positions: the default SIM gives 25 to 30 % of the supercell values, the bare shell charge 1.5 to 4 times (FINDINGS_LOG "Gate B4.5") |
| SRO between two sublattices in an SCF run | 🟢 bcc = B2 with equal sublattices to all digits; G1 on partial B2 exact; partial B2 with SRO converges (35 iterations) |

### 7. v1.0 freeze and CPC paper 🔴
From `docs/PUBLICATION_PLAN.md`: SRO gates pass, HEA SCF robust (🟢 since the `hull` fix), cost table, gfortran + OpenBLAS build, one
documented route, validation rerun with the tagged binary, short tests with reference outputs, known discrepancies documented.

Readiness check of 2026-11-05: not ready for submission.  For random alloys the code is still a slow CPA.  For HEAs it is slower than one
SQS cell.  SRO is the real difference, but its numbers are not final.  Rough estimate: 4 to 6 weeks of work with a frozen scope.

Pending decision: should `ed3` replace the literal AMscf form as the production method?  This would reverse the fixed decision above.
Recommendation: yes, if gates 2 to 4 pass.  A known factor of two in the main selling point is hard to defend.  The alternative is to
ship H^(2) and state the limit.  That is faster, but it gives a weaker paper.
